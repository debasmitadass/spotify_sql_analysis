# Spotify SQL Analysis
This project analyzes the Spotify Tracks dataset using SQL. The project contains 18 queries organized into Easy, Medium, and Hard difficulty levels to explore popularity, genres, artists, and audio features.
## Dataset
- Spotify Tracks Dataset
- 114,000+ records
- Source: Kaggle
## Objectives
- Practice SQL fundamentals and intermediate concepts.
- Analyze trends in the Spotify dataset.
- Draw insights using SQL queries.
## SQL Concepts Used
- SELECT / FROM (Data retrieval)  
- DISTINCT (Removing duplicate entries)  
- WHERE (Row-level data filtering)  
- IN (Filtering across multiple values)  
- LIKE (Pattern matching with wildcards)  
- ORDER BY (Ascending and descending sorting) 
- LIMIT (Restricting output row count)  
- GROUP BY (Data aggregation by category)  
- HAVING (Filtering grouped data)  
- Aggregate Functions (COUNT, AVG, SUM, MAX, MIN)  
- CASE WHEN (Conditional statements)  
- Subqueries (Nested inner queries for dynamic filtering) 
- ROUND (Mathematical formatting for decimals)  
## Project Structure
- Easy Queries (8)
- Medium Queries (6)
- Hard Queries (4)
